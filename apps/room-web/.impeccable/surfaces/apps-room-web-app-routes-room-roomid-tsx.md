# Room surface (room.$roomId, room._index, room.agents)

Mode: Operate. One person, several local agents, one shared stream. The task is to keep talking while replies arrive one at a time over 30–120 s each.

Audience/job: developer at their own machine, often late at night. Job: say something, watch who answers, know who is up next and how long this one has taken, keep going.

Constraints: no task UI this round (no 升级为任务, task composer, Task gate banner, board nav). No fake controls: no stop-round, no per-agent retry unless a HELD draft exists. HELD draft text never enters the 房间对话 region. Human is 「你」. Copy follows `.tmp-bin/rivus-copy.txt` §1 and §7.

Unresolved: none blocking. Avatars are two-letter monograms on a tinted disc (no image generation available; third-party anime art not sourceable/licensable).

## Direction contract

THESIS: A working stream, not a chat bubble app. The centre column is the stream; the left rail and right column are chrome that reads as chrome. It refuses the category default (cream paper, photo wash, mascot, rounded bubbles, "thinking…" dots) and the other default (dark neon terminal).

OWN-WORLD: 宣纸 — warm white paper, written in shadcn's token vocabulary. The values are the comp's; the names are shadcn's, and the controls are shadcn components from `app/components/ui` (new-york, neutral, cssVariables, phosphor icons, per components.json). The page is a sheet and the text is the subject. The rails are --sidebar (#f7f7f5 / #202020), one step darker than --background (#ffffff / #191919) and told apart from it by a single 1px --sidebar-border (#e9e9e7 / #2f2f2f), not by a field of colour; the centre is the paper itself. There is no solid field of colour anywhere, no stacked shadows, and exactly one object that floats: the composer card, which carries the single --shadow-card value and takes the focus ring as a whole block because the card is the field. Three mappings carry the world: --chart-1…5 are the five members' identity colours in seating order (claude-relay, claude, codex, opencode, dsh), colouring the author name and the two capitals in a shadcn Avatar whose fill is that hue at 15%, so identity rides shadcn's own categorical ramp instead of a set of invented --id-* names; --accent (#efefec / #2a2a2a) is the hover and selected fill, the solid equivalent of the 8% ink wash the previous round used, so rows read as text with a tint behind them rather than as filled chips; and --info / --warning / --success / --destructive-soft are four added pairs written the way shadcn writes its own — the token is the wash, -foreground is the ink on it — so a state pill is exactly `bg-warning text-warning-foreground` and one Badge variant name settles a state's whole appearance. --destructive keeps shadcn's meaning, the solid red under white text on 确认清空; the soft error wash is the separate --destructive-soft. One accent, blue #1a6fd1 / #529cca, carries links, @-mentions, the focus ring, the brand mark and the primary button. The middle grey the previous round called --ink-2 has no shadcn counterpart and is written as foreground/75; muted-foreground is the lightest colour allowed to be text and muted-foreground/60 is decoration only. Two self-hosted faces on one boundary: Inter carries every interface word and Noto Serif SC carries the prose — message bodies, the composer's editable area, the held-draft preview and the empty state — at 16px/1.7, because a serif needs more leading than a sans and because a long reply should read like an article while the labels around it still read like an interface. Both are sliced by unicode-range and swap rather than block, so the CJK the page actually uses is the only CJK it downloads. ui-monospace for timers and ids with Tailwind's built-in tabular-nums. Type steps 12 / 13 / 14 / 16 / 24, with 18 allowed once for the empty-state title and 11/10 for the mark letters; section labels are 12px/500 Chinese, never uppercase and never tracked out. Radius derives from shadcn's --radius: 0.5rem, and its three steps land exactly on the comp's — rounded-sm 4px on controls and pills, rounded-md 6px on rows and menu items, rounded-lg 8px on the things that float. Marks are 30px in the thread, 22px in lists, 36px on the desk. Below 1180px the members column stops being a grid column and becomes a shadcn Sheet on the --sidebar fill behind a foreground/20 scrim (not shadcn's black/50, which is a foreign object on this palette); only one of the two is ever mounted, chosen by matchMedia, so the document never holds a second copy of the panel's ids. Contrast was re-measured over both families shadcn cares about — every <x> / <x>-foreground pair, and every text token against every surface it actually lands on in both themes, with /75, /15 and /10 composited first: 134 pairs, minimum 4.53:1. The composer is a Tiptap editor whose schema is only Document > Paragraph+ > (Text | Mention | HardBreak): a mention is one object you delete in one keystroke and select as a chip, rendered with the member's own --chart-N at 15%, identical whether it is still being written or already posted — and it still leaves as the string `@codex`, so the server's parser is untouched. The theme is a `dark` class on <html>, shadcn's convention: the rail footer cycles follow-system / light / dark, and because there is no prefers-color-scheme query left in the CSS, follow-system resolves the query in JS and restamps the class when the system flips.

STORY: the visitor sees who is talking and for how long, who is behind them, whose draft is waiting and whose run failed, and understands that typing now is always allowed and only affects order. They act by sending, @-ing one member, waking a held draft, or checking connections.

FIRST VIEWPORT: three columns 240 / fluid / 300. Left: wordmark, nav (房间, 智能体), room list, footer line. Centre: header row with room title and one status sentence (N 位成员 · 轮到 X，后面还有 M 位), 管理成员 button; the thread; a run strip (member order as a step row, done filled, now lit with elapsed timer, queued outlined); the composer with a one-line hint and 发送. Right: 成员 with the same five states as the thread (held draft text and its one action 读取更新并重答 live here and nowhere else; the thread row for a held member is status only), then 检查连接. The room facts line the prototype put at the top of this column is deliberately dropped: the header already carries title, member count, goal and the round sentence, and a repeated title under a kicker is the eyebrow pattern the craft floor bans. Below 1180 px the right column leaves the grid and becomes a shadcn Sheet, min(320px,100%) on the sidebar fill with the card shadow behind a foreground/20 scrim; below 820 px the rail becomes a top bar.
